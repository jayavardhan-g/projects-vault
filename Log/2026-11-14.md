### Things found in the code that the older notes did not say

- `photoseek index --rebuild` re-embeds from image files; `FaissStore.rebuild_from_catalog` is called only from `tests/test_index.py`.
- The JSON schema types dates as plain strings and has no `additionalProperties: false`; nothing checks `date_from <= date_to`.
- Rule-parser quirks seen by running it: "this winter" asked in November gives the winter that already ended; "mom at christmas" gives `place="christmas"`; only one date phrase is extracted per query; lowercase names are not people.
- The default image batch size is 32 (64 is the eval scripts' flag); the default router is `rule`.
- `IndexIDMap2`'s extra reverse map (for `reconstruct`) is unused; plain `IndexIDMap` would probably also work (not tested).
